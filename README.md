# Sky Squad

브라우저에서 즐기는 2~4인 온라인 협동 비행기 슈팅 게임입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 열고 방을 만든 뒤, 방 코드나 초대 링크를 친구에게 보내면 됩니다.

## 조작

- 이동: 방향키 / WASD, 모바일은 화면 드래그
- 사격: 자동

## 규칙

- 체력이 0이 되면 6초 뒤 부활합니다. 단, 팀 전원이 동시에 쓰러지면 게임 오버입니다.
- 5웨이브마다 보스가 등장합니다. 인원이 많을수록 적 수와 체력이 늘어납니다.
- 아이템: `P` 무기 강화(최대 Lv.4), `+` 체력 회복(최대 5)

## 구조

- `server.js` — 정적 파일 제공, WebSocket 방 관리, 게임 시뮬레이션(초당 30틱, 서버 권위)
- `public/` — 클라이언트(로비 UI, 입력, 캔버스 렌더링)
- `test/smoke.js` — 두 클라이언트 접속 스모크 테스트 (`npm test`)

## 배포

WebSocket을 지원하는 Node.js 호스팅이면 됩니다. 시작 명령은 `npm start`, 포트는 `PORT` 환경 변수를 따릅니다.
